# Thomas Wang — Design Language

General UI/UX taste, not tied to any one project. Written so people and agents can design in it.

## Thesis: engineered intimacy
Precise like a drawing set, warm like a handled object, lit like a Nolan frame. Restraint is the luxury.

## Principles
1. **One living hero object per view.** Everything else recedes (askshepherd.ai's single point-cloud figure).
2. **Make the system legible.** Index numbers, leader lines, spec ribbons, exploded axonometrics (palantir.com, Ontology page; Stark's exploded suit schematics).
3. **Handmade over generated.** Pencil, paper grain, polaroid borders, film grain, lo-fi honesty (f.inc).
4. **Touch answers physically.** Cursor displaces matter, drag rotates, buttons depress, nothing is dead on hover.
5. **Narrate, don't dump.** A guided path, a progress spine, word-by-word reveals (learnwithzero.com).
6. **Miniature worlds, seen from above.** Dioramas, isometric cities, axonometric stacks.
7. **Cinematic contrast.** Deep blacks, one warm light source, navy. Interstellar, the Dark Knight trilogy, Bruce Wayne's penthouse.
8. **Composure.** Tailored and fitted: exact spacing, aligned grids, nothing loose.
9. **When it's an experience, remove the interface.** No launch screens, names or labels when the image can carry it (the Tesseract).

## Type
- Display: an editorial serif (Instrument Serif / Lora class). Two-tone headlines: 100% plus a ~55% continuation.
- UI: a sharp grotesk (Instrument Sans / Alliance No.1 class; free stand-ins: Inter Tight, Geist).
- Metadata: mono, uppercase, +6–8% tracking (Geist Mono / JetBrains Mono).
- Large numerals are welcome.

## Colour
| token | value | use |
|---|---|---|
| ink | `#050505` | immersive backgrounds |
| paper | `#F6F5F1` | editorial backgrounds |
| navy | `#0B1A33` | depth, tailoring |
| graphite | `#8A8F98` | secondary text, hairlines |
| hairline | `rgba(255,255,255,.12)` / `rgba(0,0,0,.10)` | rules |
| accent | **one per product** (e.g. sodium amber `#E8A54B`, signal green `#3DDC97`) | the only colour that speaks |

## Line, texture, motion
- 1px hairlines; iso/axonometric projection; leader lines with mono labels; dot or hex grids at 4–6% opacity.
- Film grain 3–5%, paper fibre, halftone for archival imagery, pencil-sketch backgrounds.
- Motion is weighted and slow: `cubic-bezier(.16,1,.3,1)`, 700–1400ms for scene moves, 150–250ms for UI. Prefer scroll-scrubbed motion to autoplay. Use idle "breathing" states. No bouncy springs.

## Interaction
Hardware-like docked controls with pressed states · the cursor as an instrument (loupe, repulsion) · drag to rotate or look · full keyboard navigation · sound only when it earns it (often: none).

## Imagery
Real photos, including lo-fi or fisheye; portraits with negative space; AI imagery only if labelled.

## Hard rejections
Obsidian / force-directed blob graphs · purple-gradient AI SaaS · glassmorphism everywhere · emoji UI · Inter-on-white three-card grids · neon cyberpunk HUDs · bouncy springs · undirected "data sculpture" noise · stock 3D blobs · launch screens and chrome on experiential pieces.

## Tensions (resolve per surface)
Precision ↔ warmth · restraint ↔ spectacle · dark cinema (immersive) ↔ light editorial (reading).
